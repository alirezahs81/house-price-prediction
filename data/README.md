# Dataset

This directory contains the Ames Housing / Kaggle House Prices competition data supplied with this project.

- `raw/train.csv`: 1,460 labeled records, including `SalePrice`.
- `raw/test.csv`: 1,459 records without `SalePrice`.
- `raw/sample_submission.csv`: competition-format example submission.
- `raw/data_description.txt`: supplied feature definitions.
- `processed/`: generated/optional processed artifacts; raw source files are preserved.

The files were extracted from the user-provided `data.zip` archive. The dataset is third-party competition data and is not relicensed by the MIT license in this repository. See the original Kaggle competition terms and dataset documentation before redistributing it elsewhere.
